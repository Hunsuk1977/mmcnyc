1. What Church OBS is1. Church OBS란

Church OBS is broadcasting software built on the open-source OBS engine. The free version has every feature and adds a small watermark; Pro removes the watermark and adds extras. Source code is public under its license on the project repository.

Church OBS는 오픈소스 OBS 엔진 위에 만든 방송 소프트웨어입니다. 무료 버전은 모든 기능을 쓸 수 있고 작은 워터마크가 붙으며, Pro는 워터마크가 없고 추가 기능이 있습니다. 소스 코드는 프로젝트 저장소에 해당 라이선스로 공개되어 있습니다.

You can disconnect at any time (see the privacy policy).
